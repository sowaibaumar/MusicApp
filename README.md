Music App
This is a very simple music app I made while learning SwiftUI.
It has 3 main screens:
Home Screen
Song List Screen
Now Playing Screen (main focus)
The Now Playing screen shows the song “Just the Two of Us” with:
album cover
song title + artist name
a fake progress bar
a play/pause button (changes icon but doesn’t play real audio)

I made this to learn the basics of:
SwiftUI views
navigation between screens
buttons and state variables
sliders
creating simple layouts
working with assets
This project is only for practice and does not include real music playback.

How to run the project
Open the project in Xcode
Press Run
The app will open in the iPhone simulator
You can press the play/pause button and move the slider (UI only)
